# Gap analysis

Local scanning, hidden-content inspection, browser education and pixel
reconstruction all have upstream precedents. Test a narrower candidate
contribution across PDF and DOCX. For each selected content unit, an operator
should be able to trace its source, compare independent observations, identify
the policy decision, and replay a verifier over the original and output.

A digest anchors bytes against a trusted reference. A digest alone cannot
validate selection, original authorship, or faithful rendering. A replay
verifier should rerun the declared transformation and validate the policy and
component ledger. Independent rendering and human labels should assess
legitimate content preservation separately from replay.

Use independently authored held-out documents and paired benign cases such as
OCR, metadata and accessibility text. Publish numerator and denominator for
each metric. Record skipped formats, failed parses and rendering uncertainty
separately from detection misses. Keep demonstrations confined to inert text
markers and deterministic synthetic decisions.

This gap is a working hypothesis. Compare it against the strongest available
scanner and reconstruction tools before selecting an implementation.
