preservation, and model accuracy require a larger evaluation with frozen

from docx import Document

document = Document()

severity and malicious intent. Two controls support no rate estimate.

## Test impact assessment

The new code is a research smoke entry point. Its observable contract is to
generate one benign PDF, compare expected extraction and metadata, print
structured booleans and fail on disagreement or tool error. The direct smoke
run exercises the success contract. There were no previous tests or product
behaviors to update. Unsupported tooling, disagreement and timeout are
unexercised failure paths. The script uses explicit subprocess timeouts and
generates its own input. A direct integration smoke run is the applicable
local regression gate for this research-only branch.
