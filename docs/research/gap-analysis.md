# Gap analysis

Local scanning, hidden-content inspection, browser education and pixel
reconstruction all have upstream precedents. Test a narrower candidate
contribution across PDF and DOCX. For every observed content unit, including permitted, denied and unresolved
units, an operator
should be able to trace its source, compare independent observations, identify
the policy decision, and replay a verifier over the original and output. Record
policy and tool versions, expected views, completed views and missing views.

A digest anchors bytes against a trusted reference. A digest alone cannot
validate selection, original authorship, or faithful rendering. A replay
verifier should rerun the declared transformation. Independent checks should validate ledger
completeness within declared coverage, source lineage, policy decisions and
artifact hashes. Independent rendering and human labels should assess
legitimate content preservation separately from replay.

Use independently authored held-out documents and paired benign cases such as
OCR, metadata and accessibility text. Publish numerator and denominator for
each metric. Record skipped formats, failed parses and rendering uncertainty
separately from detection misses. Keep demonstrations confined to inert text
markers and deterministic synthetic decisions.

This gap is a working hypothesis. Compare it against the strongest available
scanner and reconstruction tools before selecting an implementation.

## Measurement units for the next study

* Score structural detection per labeled component. Score semantic classification separately per labeled document and per stated ingestion task.
* Count covered views over expected views per fixture. Report failed and skipped views in that denominator with reason codes.
* Score preservation per independently labeled factual unit, including its relation to headings, table cells and accessible reading order where relevant.
* Score task completion per document-task pair with prespecified acceptable output. Score deterministic action denials separately.
* Record elapsed time and peak resident memory per process group, with hardware, versions and warmed or cold execution specified.
* Freeze all scoring rules and splits before held-out execution. Publish raw counts alongside uncertainty and keep cases from the same template family in one split.
