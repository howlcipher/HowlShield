# Roadmap

Evidence states are planned, implemented, locally verified, CI verified,
independently verified, merged, and released. Record each state with its
corresponding evidence.

| Milestone | State | Acceptance gate |
| --- | --- | --- |
| M0 Research | In progress | Primary sources, licensed competitor smoke baselines, independent alternatives and review, defensible differentiation |
| M1 Foundation | Planned | Signed history, review workflow, protected branch and reproducible lint, types, tests, and dependency checks |
| M2 Threat model and adapters | Planned | Bounded PDF and DOCX inspection with source location, integrity and coverage, plus supported TXT and Markdown contracts |
| M3 Detection | Planned | Versioned structural observations and separately calibrated interpretations with benign controls |
| M4 Differential | Planned | Independent extraction and rendered comparison with explicit adapter and layout limitations |
| M5 Reconstruction | Planned | Reproducible policy output with original hash, output hash, and verifiable preservation and exclusion records |
| M6 Containment | Planned | Resource and network isolation, fail-closed authorization, and boundary tests |
| M7 Benchmark | Planned | Frozen labeled splits, independent held-out review, uncertainty, utility, containment and performance |
| M8 Prompt Arena | Planned | Real fixture evidence, accessible comparison and synthetic demonstrations, local privacy and browser verification |
| M9 Integrations | Planned | Versioned Python, CLI, REST, schemas, CI examples and documented error contracts |
| M10 Review and release | Planned | Resolved review findings, verified regression and security gates, signed release, research report and portfolio case study |

Start with the complete PDF and DOCX slice. Expand format support after
reconstruction, verification and evaluation work together.
